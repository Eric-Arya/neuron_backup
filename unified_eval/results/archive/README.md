# Archived results

These runs are retained for provenance but excluded from the active top-level experiment scope.

- `sncorpus_dpo/` contains historical SNCorpus DPO experiments. They are not HH-corpus runs, but
  they are archived because current IA3 evaluation is restricted to SNCorpus raw SFT.
- `smoke/` contains retained Grad and SN-Tune smoke runs from the former top-level
  `smoke_results/` directory. These are provenance artifacts, not active benchmark results.
